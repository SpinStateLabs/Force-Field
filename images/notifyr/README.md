# Force Field Notifyr: brand marks (approved 2026-11-21: E3)

Notifyr is drawn as a sibling of the Force-Field icon
(`plugins/force-field/.claude-plugin/icon.png`): same dark grid tile, slate border, split
field ring with gaps at top and bottom, uniform heavy stroke, and mint/violet split on the
gap line.

| Role | Folder | What it is |
|---|---|---|
| Mark | `mark-envelope-alert/` | E3: an outline envelope at the ring's stroke weight, split mint/violet on the gap line, inside the Force-Field split ring; a violet notification dot breaks the ring at the upper right. |
| Wordmark | `wordmark-w1/` | W1, round geometric, one colour: single line, stacked, and "Notifyr" alone. Used in the lockups. |

## Rules

- Keep the notification dot. It is part of the mark, not a badge to toggle.
- On white or light surfaces use the light-theme colours only. Bright mint on white is
  1.80:1 and fails contrast.
- At 16 px use the pixel-fitted `mark-16-*.svg` / `favicon-16.svg`, not a scaled-down mark.
- All letterforms are drawn as paths. No font files are needed, and none are included.

## Palette

| Name | Hex | Use |
|---|---|---|
| Mint | `#00DBA8` | Dark theme only: left field half, approve (11.32:1 on `#04050E`) |
| Violet | `#8B6BFF` | Dark theme: right field half, deny (5.46:1 on `#04050E`) |
| Mint, light theme | `#007A5E` | Light theme only (5.32:1 on white) |
| Violet, light theme | `#6A4AE6` | Light theme only (5.62:1 on white) |

| Snow | `#EEF0F6` | Wordmark on dark |
| Slate | `#1C2033` | Tile border (decorative) |
| Grid | `#0E0F17` | Tile grid (decorative) |

## Files in each mark folder

- `mark-*.svg`: the mark in four variants (colour, colour-reversed, mono-dark, mono-light).
- `mark-16-*.svg`: a version pixel-fitted for 16 px.
- `lockup-horizontal-*.svg` and `lockup-stacked-*.svg`: the mark with the wordmark.
- `app-icon.svg`: the app icon, 1024 base.
- `favicon.svg` and `favicon-16/32/48.svg`: the favicon set.
- `png/`: exports at 1x and 2x, and icons at 16, 32, 48, 180, 192, 512 and 1024 px.

No trademark search has been done on these marks.

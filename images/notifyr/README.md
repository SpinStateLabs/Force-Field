# Force Field Notifyr: brand marks (approved 2026-11-21)

Notifyr is drawn as a sibling of the Force-Field icon
(`plugins/force-field/.claude-plugin/icon.png`): same dark grid tile, slate border, split
field ring with gaps at top and bottom, uniform heavy stroke, and mint/violet split on the
gap line.

| Role | Folder | What it is |
|---|---|---|
| Primary mark | `mark-primary-split-n/` | A geometric N in the split field, coloured on the gap line like the Force-Field F. |
| Wordmark | `wordmark-w1/` | W1, round geometric, one colour: single line, stacked, and "Notifyr" alone. |
| Backup mark | `mark-backup-decision-point/` | A disc split down the gap line: mint (approve), violet (deny). |

## Rules

- **Never place the primary and backup marks side by side.** Together the N and the disc
  read as "NO". Use one or the other in any one view, layout or screen.
- The backup mark is used only where the primary mark is not used.
- On white or light surfaces use the light-theme colours only. Bright mint on white is
  1.80:1 and fails contrast.
- All letterforms are drawn as paths. No font files are needed, and none are included.

## Files in each mark folder

- `mark-*.svg`: the mark in four variants (colour, colour-reversed, mono-dark, mono-light).
- `mark-16-*.svg`: a version pixel-fitted for 16 px.
- `lockup-horizontal-*.svg` and `lockup-stacked-*.svg`: the mark with the wordmark.
- `app-icon.svg`: the app icon, 1024 base.
- `favicon.svg` and `favicon-16/32/48.svg`: the favicon set.
- `og-card.svg`: the 1200×630 social card.
- `png/`: exports at 1x and 2x, and icons at 16, 32, 48, 180, 192, 512 and 1024 px.

No trademark search has been done on these marks.

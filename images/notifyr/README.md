# Force-Field Notifyr: brand marks (E3 approved 2026-11-21; Spin State Labs palette 2026-11-24)

Notifyr is drawn as a sibling of the Force-Field icon
(`plugins/force-field/.claude-plugin/icon.png`): same dark grid tile, slate border, split
field ring with gaps at top and bottom, uniform heavy stroke, and mint/purple split on the
gap line.

| Role | Folder | What it is |
|---|---|---|
| Mark | `mark-envelope-alert/` | E3: an outline envelope at the ring's stroke weight, split mint/purple on the gap line, inside the Force-Field split ring; a purple notification dot breaks the ring at the upper right. |
| Wordmark | `wordmark-w1/` | W1, round geometric, one colour: single line, stacked, and "Notifyr" alone. Used in the lockups. |

## Rules

- Keep the notification dot. It is part of the mark, not a badge to toggle.
- On white or light surfaces use the light-theme colours (Print Mint, Print Purple) only.
- The name is written "Force-Field Notifyr" (hyphen), never "Force Field".
- At 16 px use the pixel-fitted `mark-16-*.svg` / `favicon-16.svg`, not a scaled-down mark.
- All letterforms are drawn as paths. No font files are needed, and none are included.

## Palette

The Spin State Labs palette, from the Force-Field brand guidelines (`FORCE-FIELD-BRAND.md`,
Rev 0.1, sections 2 and 9). Mint stands for FORCE and purple for FIELD: never swap them.

| Name | Hex | Use |
|---|---|---|
| Spin Mint | `#1FDB91` | Dark theme: left ring half; FORCE states (verified, evidence) |
| Labs Purple | `#8C5CF7` | Dark theme: right ring half, alert dot; FIELD states (approval, policy, audit) |
| Print Mint | `#0F6E56` | Light-theme equivalent of Spin Mint |
| Print Purple | `#534AB7` | Light-theme equivalent of Labs Purple |
| Deep Space | `#04050C` | Tile background |
| Ink on dark | `#ECEEF5` | Wordmark on dark |
| Signal Red | `#FF3D5A` | Status only (deny, block, error); never in a mark |
| Amber | `#F0A020` | Status only (warning, pending); never in a mark |

In the product, Approve is purple and Deny is red.

## Files in each mark folder

- `mark-*.svg`: the mark in four variants (colour, colour-reversed, mono-dark, mono-light).
- `mark-16-*.svg`: a version pixel-fitted for 16 px.
- `lockup-horizontal-*.svg` and `lockup-stacked-*.svg`: the mark with the wordmark.
- `app-icon.svg`: the app icon, 1024 base.
- `favicon.svg` and `favicon-16/32/48.svg`: the favicon set.
- `png/`: exports at 1x and 2x, and icons at 16, 32, 48, 180, 192, 512 and 1024 px.

No trademark search has been done on these marks.
